Pour reconstruire la base de données StarXelem, lancer le projet CLI dédié au lieu de l'app Avalonia (qui peut être interrompu par le timeout du bash) :

```powershell
dotnet run --project src\StarXelem.cli.testdb\StarXelem.cli.testdb.csproj
```

Ce projet rebuild la DB entièrement sans UI, ce qui est plus fiable et rapide.

Supprimer la DB avant le rebuild si nécessaire :
```powershell
Remove-Item "$env:LOCALAPPDATA\StarXelem\database.db" -ErrorAction SilentlyContinue
```

Ensuite, pour capturer un screenshot de l'UI, lancer l'app avec les flags `--screen`, `--screenshot`, `--close`.

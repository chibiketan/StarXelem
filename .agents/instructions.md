## Rules

- Les messages de commit doivent TOUJOURS utiliser le format GitHub (conventional commits) et être écrits en français.

Format : `type(scope): description`

Types courants :
- `fix:` — correction de bug
- `feat:` — nouvelle fonctionnalité
- `refactor:` — refactoring
- `chore:` — tâches techniques (deps, config, etc.)
- `docs:` — documentation
- `test:` — tests
- `style:` — formatage, style

Exemple : `fix: corrige l'affichage des récompenses de mission dans l'UI`

Le corps du message peut contenir des détails supplémentaires sur les changements.
